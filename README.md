# ZionTech Clinic Queuing System

A licensed and published clinic queuing management system developed for ZionTech to organize patient flow across multiple clinic departments while supporting priority-based queue handling.

## Overview

The ZionTech Clinic Queuing System is designed to improve patient queue management, reduce waiting time, and streamline clinic operations. The system supports multiple departments and implements a priority-based queuing process for better patient accommodation.

Patients are categorized into:

- Normal Patients
- Priority Patients

The system follows a First Come, First Serve process while automatically prioritizing priority patients over normal patients in the queue.

## Features

- Multi-department clinic queue management
- Priority-based patient queuing
- First Come, First Serve queue processing
- Real-time queue monitoring
- Automated queue numbering
- Queue status tracking
- Admin management panel

- Database-integrated system

## Queueing Logic

The system processes queues using:

- First Come, First Serve for regular patients
- Automatic queue prioritization for priority patients

Priority patients are always served before normal patients regardless of queue order while maintaining organized patient flow within each department.
